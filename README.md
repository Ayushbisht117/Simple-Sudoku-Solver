# Sudoku Solver

A Java-based Sudoku Solver that solves a 9x9 Sudoku puzzle using the Backtracking algorithm.

## Features
- Solves 9x9 Sudoku puzzles
- Uses recursion and backtracking
- Prints unsolved puzzle
- Displays solved puzzle
- Detects if no solution exists

## Technologies Used
- Java
- IntelliJ IDEA
- Backtracking Algorithm

## How to Run
1. Open project in IntelliJ IDEA
2. Run `SimpleSudokuSolver.java`

## Input Format
- Use `-1` for empty cells
- Enter given numbers directly

## Concepts Used
- Recursion
- Backtracking
- 2D Arrays
- Constraint Checking

## Output
- Displays unsolved Sudoku
- Prints solved Sudoku grid
